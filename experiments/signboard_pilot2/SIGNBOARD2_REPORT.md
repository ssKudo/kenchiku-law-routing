# 看板パイロット v2 報告

実施：2026-11-14（クドウの依頼）。対象は v1 と同一：共通テスト5問（2017 No.21 建築士法3条／No.22 同20条／No.24 都市計画法58条の2／No.4 施行規則3条の2／No.1 施行令112条）の baseline top-30 プール123条文。問題・プール・採点方法は v1 と同一で、変えたのは看板の書き方だけ。

## 0. 結論を先に

- **TF-IDF（言葉数え）では、看板v2は v1 より良くなった**。原文＋看板：平均順位 5.4（v1）→ **4.6（v2）**。v1で悪化した No.22 が 8位→4位に直り、No.24 は 3位→2位。ただし No.21 は 5位→6位と少し悪化し、top-3 は 2/5 で v1 と同じ。
- **看板だけで並べる「分岐」の代理指標でも v2 が上**：看板のみ順位の平均 11.4（v1）→ 9.0（v2）、top-20 残存は 4/5 → **5/5（全問残存）**。No.24 は看板だけで1位になった。一方、対照問 No.1 は看板のみだと 12位まで落ちた（原文が1位の問では、看板への置き換え自体が情報の損失になる）。
- **Qwen2.5-1.5B に看板v2を読ませて分岐させる条件は 0/5**。正解条文の看板は5問とも選ばれなかった。出力の形は完璧（全問クリーンな番号3つ）だが、選ぶ番号が問題によらず似た並び（14番が3問、25番が3問）に寄る——選択実験v1で見た「形だけの選択」と同じ失敗の形。**文章をやさしくしても、1.5Bの「30件から番号で選ぶ」判断はできるようにならなかった**。
- 留保：看板v2は v1 の約2.9倍の分量がある（平均242字 vs 82字）。改善の一部は分量の効果かもしれない。ただし質問タグは166字で平均4.0・top-3 3/5 と、v2看板（242字）より少ない分量でより良い結果を出しており、「何を書くか」の方が分量より効いている可能性が高い（§6）。

## 1. 看板v2の書き方（クドウの定義どおり）

v1の仕様は「1〜2文の平易な要約＋日常キーワード」で、これはエミリーの側の運用解釈だった。v2はクドウの本来の定義で書き直した：

- やさしい言葉で書くが、**その条文だけの特徴（固有の数字・手続き・対象・例外）は落とさない**
- **条文ごとに言い方を変える**。同じ概念（届出・手続き・許可・認定など）を全条文で同じ言い回しに揃えない
- 短くまとめなくてよい（長くなって構わない）
- ブラインド規則は v1 と同じ：条文本文だけを見て書き、問題文・正解条文は見ていない

書き終えた後に**衝突チェック**を実施：全123件の看板同士について、字n-gram類似度（Jaccard）とキーワード重複を機械抽出し、目視で判定した。見つけた実害は「資金計画が適切」というキーワードが認定系4条文（省エネ法30条・耐震改修法17条・長期優良住宅法6条・バリアフリー法17条）で完全一致していた点で、各条文固有の表記に書き換えた。あわせて施行令109条の10の書き出し変更、建築士法24条の7のキーワード差別化を行い、計6件を書き換えた。残る高類似ペア（耐火構造ファミリー、免許証交付と登録簿、都市計画法52条の2と53条など）は条文自体が本質的に近いペアで、キーワード側に固有の差別化（数値・対象・手続の違い）が効いている範囲と判断した。

## 4. Qwen 分岐条件（クドウの追加指示）

狙い：看板＝やさしい文章なら、日常文の二択で84%正解した Qwen2.5-1.5B が、法令でも分岐できるのではないか——というクドウの仮説の検証。

方法：各問のプール30条文の看板v2を番号付きで Qwen に提示し、問題文（＋選択肢）に合う看板を番号で最大3つ選ばせた。実行環境は small_model_test と同一（llama.cpp llama-completion、ChatML、temp 0.2、seed 42、スレッド4。看板30件でプロンプトが約6,100〜6,900トークンになるためコンテキスト長 8192 のみ明示、生成条件は不変）。パース規則も選択実験と同一。LFM3 は使っていない（クドウの判断どおり）。生出力は qwen_branch_results.json に全量保存。

結果：**正解の生存 0/5**。

| 問 | 正解条文（看板番号） | Qwen の生出力 | 選ばれた条文 | 生存 |
|---|---|---|---|---|
| No.21 | 建築士法3条（#5） | `13, 14, 25` | 法6条／士法10条の22／士法22条の2 | ✗ |
| No.22 | 建築士法20条（#7） | `14, 15, 25` | 法5条の6／法6条／省エネ法63条 | ✗ |
| No.24 | 都市計画法58条の2（#5） | `1, 2, 12` | 都計43条／都計34条／建設業法9条 | ✗ |
| No.4 | 施行規則3条の2（#10） | `14, 15, 26` | 規則8条の2／バリアフリー法17条／士法18条 | ✗ |
| No.1 | 施行令112条（#1） | `23, 25, 28` | 令109条の10／令129条の13の3／法50条 | ✗ |

失敗の形：

- **形は完璧**。5問とも説明文なしの番号3つだけを返し、パース失敗・範囲外・切り捨てはゼロ。1問あたり約187〜216秒（プロンプト処理が大半）。
- **中身は問題を見ていない疑いが濃い**。採用番号の頻度は 14番が3問、25番が3問、15番が2問。No.21（13, 14, 25）と No.22（14, 15, 25）は、問題も看板リストの中身も全く違うのに2つが重なる。選択実験v1で「違う問題・違うリストなのに同じ選び方をした」のと同じ形。
- No.1 では正解の看板がリストの先頭（#1）にあったのに選ばれず（23, 25, 28）、No.24 では先頭2件（#1, #2）を拾った。先頭だから選ぶ／選ばないの単純な位置バイアスとも言い切れない。
- 対照として、**同じ看板v2を TF-IDF（言葉数え）で並べると No.24 の正解は1位、No.22 は4位**だった。看板の文章自体に問題と結びつく手がかりは入っている。Qwen はそれを読み取って選ぶ段階で失敗している。

解釈（留保つき）：この条件が測ったのは「1.5B が30件・約6,500トークンのリストを一度に読んで番号で選ぶ」という形式で、これは選択実験v1で既に弱さが確認された形式そのもの。「やさしい文章なら二択はできる」（日常文チェック）の成功条件は、短い文×2択だった。30件からの番号選択は、文章の難しさとは別のところ（長いリストの保持と番号への対応づけ）で躓いている可能性がある。2択ずつ絞る形式や、件数を絞った分岐は未検証。n=5 のパイロットであることも割り引く必要がある。

## 5. 実例：看板 v1 → v2

### No.22（v1で悪化 7→8、v2で改善 →4）— 建築士法20条

- **v1**：「建築士が業務に関して表示行為（看板や広告などの表示）をする場合に、一級建築士・二級建築士・木造建築士の別が分かるように表示しなければならないという決まり。」（キーワード：表示行為／広告／看板／一級建築士／二級建築士／木造建築士／表示）
- **v2**：「建築士が仕事をしたときに、形に残して相手へ渡さなければならないものを定めた条文。図面を引いたら、その設計図書に『○級建築士』と分かる表示をして名前を書く（一部を変えたときも同じ）。構造計算で建物の安全を確かめたら、その証明書を遅らせず設計を頼んだ人へ渡す。現場のチェック（工事監理）が終わったら、すぐに結果を文書で建て主に知らせる……」（キーワード：設計図書に表示して記名／証明書を交付／工事監理の結果を文書で報告／直ちに報告 ほか）
- 何が違ったか：v1 は条文のごく一部（表示の別）だけを、しかも「看板や広告」という日常語に寄せて書いたため、問題文の問う中身（図書への表示・記名、証明書の交付、監理報告）と結びつかず、逆にライバル 24条の8（契約書面交付）の看板の方が橋になった。v2 は条文の実際の構成要素を全部、固有の言い回しで残したので、正解側のスコアが 942 → 1010 に伸びた。なおライバル 24条の8 の v2 看板も「契約が成立したあとの書面の受け渡し」と時点を明示して差別化されており、v1 のような取り違えが起きにくくなっている。

### No.24（v1で改善 5→3、v2でさらに改善 →2、看板のみでは1位）— 都市計画法58条の2

- **v1**：「地区計画の区域（地区整備計画などが定められた区域）で建築や土地の区画形質の変更などをするときは、着手する日の30日前までに市町村長へ届け出なければならないという決まり。届出の内容が地区計画に合わないときは、市町村長が設計の変更などを勧告できる。」（キーワード：地区計画／届出／30日前／市町村長／建築／勧告）
- **v2**：「地区計画が決まっている区域の中で、土地の形を変えたり建物を建てたりするときの、市町村長への届出。……工事に取りかかる日の30日前までに、行為の種類・場所・設計や施工の方法・着手の予定日などを市町村長に届け出なければならない。届けた内容を変えるときも、変更する行為の30日前までに届け出る。……」（キーワード：地区計画の区域／三十日前までに届け出／市町村長に届け出／設計の変更を勧告／行為に着手する日の三十日前／地区整備計画 ほか）
- 何が違ったか：v1 の改善は「30日前」という言い換えの橋によるものだった。v2 はそれに加えて、届出の中身（種類・場所・設計・着手予定日）と「変更も30日前」という第二の届出まで残し、漢数字表記（三十日前）とアラビア数字表記の両方をキーワードに入れたため、問題文との一致点が増えた。

## 6. 判定と留保

- 看板v2（クドウの定義どおりの書き方）は、v1（エミリーの要約解釈）より測定上はっきり良い。原文と併用すれば平均 4.6、看板だけでも top-20 に全問残る。**「やさしくしても違いが消える」のではなく、「やさしく、かつ違いを残す」書き方が効いた**——これはクドウの指摘どおりだった。
- ただし分量の留保は消えない。v2 は v1 の約2.9倍の文字数がある。反証材料として、質問タグは166字で平均4.0・top-3 3/5 と v2（242字で平均4.6・top-3 2/5）より良い。つまり「長く書けば勝ち」ではなく、質問タグの「聞かれ方を先回りする」中身の方がなお強い。看板v2の改善が「固有の特徴を残したから」なのか「単に長いから」なのかの切り分けは、この5問では完全にはできない（No.22・No.24 の実例では、v1が落としていた固有要素の復活が効いた形跡が具体的にはある）。
- Qwen 分岐は 0/5 で、仮説はこの形式では支持されなかった。日常文でできたのは「短い文×2択」で、今回の「長いリスト×番号選択」は別の能力を要求する。看板の文章自体は TF-IDF で機能しているので、看板が悪いのではなく、1.5B の選び方の問題として切り分けられる。
- 悪化した点を隠さず書く：原文＋看板v2 で No.21 が 5→6（スコア自体も微減）。看板のみ条件では対照問 No.1 が 3位（v1）→12位（v2）に悪化し、No.4 も 18位と弱いまま。
- n=5 のパイロットであり、全数値に大きな不確かさがある。本格展開（全条文への看板付け）の判断はクドウに委ねる（今回のスコープ外）。

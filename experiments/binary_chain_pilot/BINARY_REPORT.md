# 二択の連続パイロット 報告書

日時: 2026-11-12
対象: 過去問5問(2017年 No.21, 22, 24, 4=入口ミス、No.1=対照)、候補プール各問30条(123条)
モデル: Qwen2.5-1.5B-Instruct GGUF Q4_K_M、llama.cpp (llama-server)、temperature 0.2、seed 42

## 結論

**二択の連続は、○×とは明らかに「違った」。だが順位は良くならなかった。**

- ○× (v5・アキネーター式) のような「全部×」への崩壊は起きなかった。名前のある二択では両方のラベルが選ばれ、答えた回の出力は90回中68回すべて「ラベルそのまま」のクリーンな形式だった (形式の汚れ0件)。強制二択という形式自体は 1.5B の能力内にある。
- しかし中身の選択が弱く、多数決条件の順位は baseline を5問中4問で下回り、改善は1問 (No.4: 10→8位) のみ。トップ3入りは0/5問。対照問 No.1 も 1→6位に悪化した。
- oracle (正答条自身の側を選択に使った場合) は 2・1・1・1・1位で、天井は高い。**律速は今回もモデルの選択の質**である。ただし正答条に「側」がある軸が少ない問 (No.21 は 2/6軸) では、方式側の天井も制限される。

## 位置バイアスと一貫性の診断

- **順序入替の一貫性 73.7%** (rep1[AB提示] と rep2[BA提示] で同じラベルを選んだ割合、有効ペア19件)。残り26.3%は提示順を入れ替えると選択が反転した。
- 同じ提示順の再現性 (rep1 と rep3) は 100% (有効ペア23件)。同じ聞き方をすれば同じ答えが返る。
- **「最初に提示されたラベル」が選ばれた割合は全体で 63.2%**。ただし提示順で大きく違う:
  - AB提示 (rep1・rep3): 52.2% — ほぼ半々
  - BA提示 (rep2): **86.4%** — 最初に出た B 側ラベルに強く流れる
- ラベル自体への偏りも重なっている。全68回の有効選択の内訳は A側ラベル27回・B側ラベル41回。特に「建物そのものの話」(13回/15回中)、「契約・書面の話」(10回) が選ばれやすく、「資格を持つ人の話」は15回中2回しか選ばれなかった。No.22 (管理建築士の業務が主題) でも3回とも「建物そのものの話」だった。位置の癖と、無難なラベルへの偏りが合わさったものと見られる。

## 形式崩れの内訳

- 90回中22回 (24.4%) が形式崩れ、**全て「ラベルを書かず、試験の選択肢を復唱・継続する」型** (both_labels は0件)。勝手な補正はしていない。
- 軸別では「言葉の定義の話 vs 罰則・処分の話」に集中 (15回中12回が崩れ)。どちらのラベルも問題に結びつけにくい軸で、モデルは答えられずに問題文の復唱へ倒れたと見られる。「火災 vs 構造」も 7/15回が崩れた。
- 多数決が取れなかったのは 30組中4組 (No.21・24・4 の定義軸、No.24 の火災軸)。その軸は全条文不一致として扱った。

## 具体例: No.21 (建築士法、一級建築士の業務範囲の問題) でモデルが選んだラベル

| 軸 | モデルの選択 (3回) | 多数決 | 正答条(3条)の側 |
|---|---|---|---|
| 建物の安全 vs 手続き・人 | 安全、安全、(崩れ) | 建物の安全の話 | 手続き・人の話 |
| 火災 vs 構造・重さ | (崩れ)、構造、(崩れ) | 構造・重さの話 | 中立 |
| 資格を持つ人 vs 建物そのもの | 資格、建物、資格 | 資格を持つ人の話 | 建物そのものの話 |
| 役所との手続き vs 契約・書面 | 契約、契約、契約 | 契約・書面の話 | 中立 |
| 土地・区域 vs 建物の設備 | 設備、設備、設備 | 建物の設備の話 | 中立 |
| 定義 vs 罰則・処分 | (崩れ)×3 | なし | 中立 |

- 「資格 vs 建物」では、提示順を入れ替えた回だけ最初に出た「建物そのものの話」に流れた (位置バイアスの実例)。
- 正答条に側があるのは6軸中2軸だけで、その2軸ともモデルの選択と食い違い、一致数は 0/3 (プール最大3) となり29位まで沈んだ。

## 方式の天井 (oracle) との切り分け

- oracle 順位は 2・1・1・1・1。選択が正答条の側と一致すれば、この軸+側付けの設計でも正答条はほぼ1位に来る。方式の上限は悪くない。
- ただし側付けの構造的な弱さもある: 完全同点の条文は「中立」としたため、軸によってはプールの大半が中立になる (定義 vs 罰則は123条中113条が中立、火災 vs 構造は66条、土地 vs 設備は65条)。No.21 の正答条は側のある軸が 2/6 しかなく、モデルが全軸正しく選んでも一致数は最大2にしかならない。それでも oracle が2位なのは、ライバルも同じく絞られるため。
- つまり今回の失敗は「モデルの選択の質」が主因で、「中立の多さによる天井の低さ」が副因。

## 実行条件と速度

- 90回 (5問×6軸×3回) で合計 191.6秒 (約2.1秒/回)、サーバ起動 12.2秒。プロンプトは問題文+選択肢+二択ラベル、数字・記号の例示は入れていない。

## 課題として記録 (今回は直さない)

- 「定義 vs 罰則」のような、どちらの話題も大半の条文・問題に薄い軸は、モデルが復唱に倒れる温床になった。軸は「どちらかが必ず問題に触れる」対で組むべきかもしれない。
- BA提示で最初に流れる癖 (86.4%) への対策として、提示順をランダム化した多数決や、ラベルへの偏りを差し引く補正が考えられる。
- 「資格を持つ人の話」のような、問題の主題そのものなのに選ばれにくいラベルの存在。ラベルの言い回し自体の見直し余地。

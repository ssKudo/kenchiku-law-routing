# リランキング測定レポート（cross-encoder）

**測った仕組み＝採点専用モデル bge-reranker-v2-m3（生成なし）で、言葉数え（TF-IDF）の上位30条文プールを並べ替えた。** 問題文と条文を1組ずつモデルに読ませて「合う度」の点数を付け、その点数だけで順位を決め直す。生成モデルではないので、くうぇんのリスト選択の失敗（連番・写し）とは別の担い手で同じ「並べ替え」を試したことになる。

## 結果（50問・プール内42問で集計）

| 条件 | top-3 | 平均順位 |
|---|---|---|
| 言葉数えベースライン（原文） | 29 | 3.88 |
| 最良スタック（原文＋単語タグ＋メタデータ） | 31 | 3.38 |
| **cross-encoder リランク（今回）** | **13** | **9.33** |
| 完璧な並べ替えの天井 | 42 | 1.00 |

**結論：はっきり負けた。** 参照値2つは集計時に再計算して完全一致を確認済み（29/3.88、31/3.38）。

### 動きの内訳（ベースライン比、42問）
- 順位が上がった 9問 / 下がった 29問 / 同じ 4問
- top-3 に入った 3問 / top-3 から落ちた **19問**
- 大きな押し上げ： 2017-6（20→7）、2022-18（24→12）、2020-3（7→1）、2021-1（4→1）
- 大きな押し下げ： 2018-5（2→27）、2020-2（2→27）、2025-9（5→27）、2017-11（2→23）、2021-20（6→25）
- 順位分布： 1位 8問（ベースラインは18問）、2–3位 5問、4–10位 13問、11–20位 10問、21–29位 6問、最下位30位は0問

### 失敗の形
- 「全く見当違い」ではない。1位を8問取っているし、大幅に押し上げた問題もある。ただし、言葉数えが2位に置いていた正解を27位まで落とすような、**確信を持った外し方**をする（例：2018-5 では正解条文の点数 −6.26 に対しプール最高は −2.87。モデルは正解を「合わない」と強く判定している）。
- 窓の数のせいではない： 単窓で全文が入る条文でも平均 −2.0 位の悪化。長い条文のサンプリング（後述）は主因ではない。
- 構図としてはベクトル測定と同じで、**一般用の「意味」物差しが、試験の言葉（条文の用語そのまま）で書かれた問題では言葉数えに勝てない**。このモデルは主にウェブ検索系の関連度で訓練されており、「4–5個の記述のうち誤っているものはどれか」という試験問題の塊と「その問題を律する条文」の関係は、訓練分布の「質問と答え文書の関連」とは別物だった、というのが一番素直な読み。

## 方法の詳細
- 土俵： fifty_measurement の50問、原文 TF-IDF 上位30条文プール（既存資産を再利用）。問題文 = stem＋選択肢（measure50 と同一）、条文 = プール原文テキスト。
- モデル： bge-reranker-v2-m3（約568M、多言語、cross-encoder）。PyTorch が使えないため ONNX で実行。
- 長い条文の扱い： 条文は中央値605トークン・最大48,557トークンと非常に長い。窓幅＝512−（問題文＋特殊トークン4）、重なりなし、**最大4窓**。4窓を超える条文は全体から等間隔に4窓をサンプリング（先頭窓は必ず含む）。条文の点数＝窓の最大値。全ペア数 4,109、採点時間の合計 約111分（1.65秒/ペア）。
- 量子化： 公式に ONNX 版が無く、入手した量子化エクスポート2件は（1）グラフ形式エラーで読み込み不可、（2）全スコア NaN、と使えなかった。最終的に fp32 の ONNX エクスポート（EmbeddedLLM 版）を入手し、**onnxruntime 標準の動的量子化に相当する置換を手作業で適用**した（MatMul 72個の重みを出力チャネル単位で int8 対称量子化し、DynamicQuantizeLinear＋MatMulInteger に置換。Attention 融合op・Gemm・埋め込みは fp32 のまま）。検証： 同一18ペアで fp32 との相関 Pearson 0.991 / Spearman 0.963、NaN なし。**量子化が敗因とは考えにくい。**
- 実行中の事故： 測定プロセスが 45/50 問の時点で一度死んだ（待機シェルへの SIGTERM と同時刻）。問題ごとに逐次保存していたため、残り5問だけ再開して完走した。データの欠けはない（全問30条文分のスコアを確認済み）。

## 留保
- 使ったのは一般用・多言語のリランカー1つだけ。日本語で追加訓練された同系モデル（hotchpotch/japanese-bge-reranker-v2-m3 等）は未測定。
- 問題文は選択肢全部入りの塊で1回だけ採点した。XLaw-JP-27B のように「選択肢ごとに」検索・採点する設計は別の形で、未測定。
- 窓サンプリングの上限（4窓）は計算量の都合。全窓方式は未測定（ただし単窓条文でも負けているので、結論が反転する見込みは薄い）。
- 土俵はいつも通り TF-IDF の上位30プール内。プール外の8問には何をしても届かない。

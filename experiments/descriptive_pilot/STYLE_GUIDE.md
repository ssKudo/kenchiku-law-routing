# 様式ガイド：「優しく言い換える」＝言葉を描写の束にほどく

クドウの定義（原文）：「リンゴ」を優しく言うなら「丸くて赤い、甘くて少しだけすっぱさがある果物」。
つまり難しい言葉を**別の名前に替えるのではない**し、**短く要約するのでもない**。
**その言葉が指しているものを、やさしい特徴の言葉の束で描き直す**こと。

## ルール

1. **名前の置き換え禁止**：難しい語を別の語（同義の専門語・略語・別の固い言葉）に替えない。必ず特徴の束にほどく。
2. **要約禁止**：内容を削らない。項・号・ただし書き・例外まで全部変換する。「など」で丸めて落とさない。長くなってよい。
3. **特徴語の共有**：下の辞書にある概念は、辞書の「芯の特徴語」を必ず含める。文の外側の言い回しは変えてよい（バリエーション推奨）が、芯は問題文側・条文側・全件で共通に残る。これにより言葉数えでも特徴語の一致が数えられる。
4. **近い概念の差は描写で残す**：届出／申請／報告／許可のように似た概念は、肝の違い（出すだけ／お許しをもらうために出す／終わってから知らせる）が描写の違いとして残ること。全部同じような文にしない。
5. **識別子は残す**：法令の名前（建築基準法、建築士法など）と条・項の番号は、名前・番号として残してよい。他条文への参照は「○条の決まり」の形で数字を残す。
6. **ほどいた語の原文は併記しない**：変換文の中に、ほどいた専門用語そのものを残さない（純粋な描写文にする）。辞書にない固有名詞（人名・地名・団体名）はそのまま残す。

## ほぐし方（特徴の問い）

難しい言葉に出会ったら、次の問いへの答えをやさしい言葉で並べる：
- 誰が／誰に（人・役所・立場）
- 何をする（出す・見張る・調べる・手渡す・知らせる…）
- いつ（始める前に／最中に／終わったあとで／すぐに）
- 何のために（よいか決めてもらうため／合っているか確かめるため…）
- どうなる（それがないと進められない／出しておけば進めてよい…）
- 見た目・性質（形・大きさ・強さ・材料など、物の言葉の場合）

## 芯の特徴語辞書（MUST = 必ず含める芯。言い回し例はバリエーションの種）

### 手続き
- **届出**：MUST「書いたものを出す」「出す相手が決まっている」「出しておけば進めてよい（よいかどうかの返事を待たない）」。例：「必要なことを書いたものを、決まった相手にあらかじめ出しておく。出しておけば進めてよい」
- **申請**：MUST「よいかどうか決めてもらうために出す」「相手がよいと言うまで進められない」。例：「やってもよいか決めてもらうために書いたものを出す。相手がよいと言うまでは始められない」
- **報告**：MUST「終わったこと・分かったことを」「あとから」「知らせる」。例：「終わったあとで、その結果を相手に知らせる」
- **許可**：MUST「決める立場の人が」「やってよいと言う」「それがないとできない」。例：「役所が『やってよい』と言うこと。それがなければできない」
- **認定**：MUST「決まりに合っているか調べて」「合っていると認める」。例：「決まりに合っているかを調べてもらって、合っていると認めてもらうこと」
- **確認（建築確認）**：MUST「建てる前に」「決まりに合っているか調べてもらう」「合っていると認めてもらう」。
- **承諾・承認**：MUST「相手がよいと言う」。
- **交付**：MUST「紙などを」「相手に手渡す」。
- **提示**：MUST「相手に見せる」。
- **検査**：MUST「決まりに合っているか」「実際に調べて確かめる」。完了検査は「工事が終わったあとの」、中間検査は「工事の途中の」を付ける。
- **登録**：MUST「決まった帳簿に」「名前を書き入れてもらう」。

### 人・機関
- **建築主**：MUST「建物を建てようとして」「頼む側の人」。例：「建てようとして頼んだ人」「建物の持ち主になる側の人」
- **特定行政庁**：MUST「その土地で」「建築の決まりを扱う」「役所」。例：「その場所の建築の決まりを扱う役所」
- **建築主事**：MUST「建てる前の調べをして」「よいかどうかを決める」「役所の担当の人」。
- **国土交通大臣**：MUST「国の」「建築や土地を担当する役所の」「一番上の人」。
- **都道府県知事**：MUST「県の」「一番上の人」。**市町村長**：MUST「市や町の」「一番上の人」。
- **建築士**：MUST「建物の設計や工事の見張りの」「資格を持った人」。一級＝「一番上の資格」、二級＝「真ん中の資格」、木造＝「木の建物専門の資格」。管理建築士＝「事務所をまとめる資格を持った人」。
- **建築設備士**：MUST「建物の電気や水道や空調などの設備に詳しい」「資格を持った人」。

### もの・行為
- **設計**：MUST「建物の形や作りを考えて」「図面や書類に描くこと」。
- **設計図書**：MUST「形や作りを描いた」「図面や書類の集まり」。
- **工事監理**：MUST「工事が図面のとおり進んでいるか」「見張る」。例：「図面どおりに工事が進んでいるかを見張る仕事」
- **施工**：MUST「実際に工事をすること」。
- **構造計算**：MUST「地震などの力で壊れないか」「数字で計算して確かめる」。
- **証明書**：MUST「確かめたことを書いた」「紙」。
- **記名**：MUST「名前を書く」。**押印**：MUST「はんこを押す」。**署名**：MUST「自分で名前を書く」。**表示（〜である旨の表示）**：MUST「〜であることが分かる印を付ける」。
- **免許**：MUST「資格があることを認める」「国の紙（またはその認め）」。免許証＝「資格があることを示す紙」。
- **敷地**：MUST「建物が建つ土地」。
- **延べ面積**：MUST「各階の床の広さを全部足した広さ」。
- **避難**：MUST「火事などのとき」「人が安全なところへ逃げる」。
- **耐火構造**：MUST「火事でも」「しばらくの間壊れず」「燃え広がらない作り」。
- **用途**：MUST「建物の使われ方・目的」。
- **政令で定める**：MUST「国の細かい決まりで決められた」。**省令で定める**：MUST「担当する役所の細かい決まりで決められた」。

### 文の決まりごと
- 〜しなければならない → そのまま「〜しなければならない」でよい（既にやさしい）。〜してはならない → 「〜してはいけない」。〜することができる → 「〜してもよい／〜できる」。当該〜 → 「その〜」。〜に係る → 「〜についての」。〜の場合において → 「〜のとき」。遅滞なく／直ちに → 「すぐに」。あらかじめ → 「前もって／始める前に」。
- **数字は半角アラビア数字に統一**する（三十日→30日、三千平方メートル→3000平方メートル）。単位は「平方メートル」「メートル」「日」「年」「階」と書く。％はそのまま。

## アンカー例1（条文側）：建築士法20条

原文（第1項）：「一級建築士、二級建築士又は木造建築士は、設計を行つた場合においては、その設計図書に一級建築士、二級建築士又は木造建築士である旨の表示をして記名しなければならない。」

変換：「建物の設計をする一番上の資格、真ん中の資格、木の建物専門の資格を持った人は、自分が建物の形や作りを考えて描いた図面や書類を作ったときは、その図面や書類に、自分がどの資格を持った人であるかが分かる印を付けて、自分の名前を書かなければならない。」

（第3項の変換例）原文：「建築士は、工事監理を終了したときは、直ちに…その結果を文書で建築主に報告しなければならない。」→ 変換：「資格を持った人は、工事が図面のとおり進んでいるかを見張る仕事が終わったときは、すぐに、その結果を紙に書いて、建物を建てようとして頼んだ人に知らせなければならない。」

## アンカー例2（問題側）：2017 No.22 選択肢4

原文：「建築士事務所を管理する建築士は、当該建築士事務所に属する他の建築士が設計を行った建築物の設計図書について、管理建築士である旨の表示をして記名及び押印をしなければならない。」

変換：「設計をする人たちが働く事務所をまとめる資格を持った人は、その事務所にいる別の資格を持った人が形や作りを描いた建物の図面や書類について、自分がその事務所をまとめる人であることが分かる印を付けて、名前を書いて、はんこを押さなければならない。」

（条文側アンカーと「図面や書類」「分かる印を付けて」「名前を書く」という特徴語が重なるのが要点。文全体は同じにならない。）

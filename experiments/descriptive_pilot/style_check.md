# 様式自己点検（パイロット123条文＋5問）

変換がクドウの定義どおりかを、実例と機械チェックで点検した。

## 1. 名前の置き換えになっていないか

- 建築士法20条（私のアンカー変換）：「表示をして記名」→「自分がどの資格を持った人であるかが分かる印を付けて、自分の名前を書く」。「構造計算によって安全性を確かめた」→「建物が地震などの力で壊れないかを数字で計算して確かめた」。名前の交換ではなく、行為の中身を特徴の束で描いている。
- 機械チェック：ほどいたはずの主要専門用語が看板側テキスト（全415,484字）に何回残っているか数えた。
  - 届出 0回／申請 0回／許可 0回／設計図書 0回／工事監理 0回／特定行政庁 0回／建築主事 0回／延べ面積 0回
- 既知の例外1件：施行規則3条の「読み替え」規定は、置き換え対象の原文文字列を引用で特定する構造のため、引用内だけ原文語（認定書・適合判定通知書等）を識別子として保持した（バッチ02の報告どおり）。

## 2. 両側で特徴語が共有されているか

No.24（都市計画法58条の2の届出）が好例：
- 問題側（選択肢4の変換）：「その行いを始める日の**30日前までに**、行いの種類、場所、始める予定の日などを**書いたものを**、市や町の一番上の人に**出しておかなければならない**。これは、**よいかどうかの返事をもらうためのものではない**」
- 条文側（58条の2の看板）：「その行為に取りかかる日の**30日前までに**、…行為の種類、場所、…を取りかかる予定の日、その他…事柄を、市や町の、一番上の人に、**書いたものを出すことで知らせなければならない**。書いたものを出すときは、出す相手が決まっており、**出しておけば進めてよい（よいかどうかの返事を待たない）**」
- 「30日前までに」「書いたものを出す」「市や町の一番上の人」「よいかどうかの返事」が両側に共通して現れる。一方で「始める／取りかかる」「行い／行為」のような外側の違いも残っている（＝バリエーション）。

## 3. バリエーションの実例（届出）

同じ「届出」でも、看板ごとに文の形は違う：
- 消防法11条：「…たものを出すことで知らせなければならない。書いたものを出すときは、出す相手が決まっており、出しておけば進めてよい（よいかどうかの返事を待たない）」
- 建築士法11条：「…書いたものを出すことで知らせるときは、出す相手が決まっており、出しておけば進めてよい（よいかどうかの返事を待たない）」
- 建築士法26条：「…書いたものを出すことは、出す相手が決まっているもので、出しておけば進めてよい（よいかどうかの返事を待たない）」
芯（出す／相手が決まっている／出しておけば進めてよい／返事を待たない）は共通、外側は入れ替わっている。

## 4. 近い概念の差が残っているか

- 申請（建築基準法6条の2の看板）：「建てる前に決まりに合っているか調べてもらって合っていると認めてもらうことを求める、**よいかどうか決めてもらうために出すこと（相手がよいと言うまで進められないもの）**」— 届出の「出しておけば進めてよい」と正反対の芯（待たないと進められない）が明示されている。
- 報告（建設業法28条の看板）：「**終わったこと・分かったことをあとから知らせる**やり方で知らせ…なければならない」— 「あとから」という時間の芯が届出・申請と書き分けられている。
- 準耐火構造（建築基準法2条、バッチ08の判断）：耐火構造の芯（火事でもしばらく壊れず燃え広がらない作り）と混同しないよう「火が広がるのを抑える力のある作り（準じた作り）」と書き分けられた。

# 参照・委任グラフ プロトタイプ v0.2 — 告示層の追加（2026-11-11）

v0.1 の文脈組立てに第3層として**告示**を足した。物差しは v0.1 と同じクドウの定義：
「正確に確定したデータ」ではなく「辿れる材料を集めて文脈に含める」。
告示についても、溶け込み（改正適用済みの現行文）や現行性の確定はしない。
代わりに、原文テキスト＋文書番号＋出典URLを保持し、検証可能な形で候補を提示する。

## 収集（コーパス）

- 出典：国土交通省「告示・通達一覧」Excel（2026-11-09更新、全5,295件）
  https://www.mlit.go.jp/notice/ 配布の一覧そのものを使用（mlit-kokuji / Kokuji_DB と同じ一次情報源）
- 抽出条件：件名が11法令クラスタの法令名を含む、または組織が住宅局系 → 893件
  → そのうち文書番号が「告示」のもの **301件**
- 本文取得：PDF直接リンク258件＋ランディングページ経由の本文17件 = **275件（91%）のテキスト化に成功**、合計 約114万字
- 根拠条文の解析：件名＋本文冒頭2,000字から「法令名＋第X条」を抽出 → **251件（83%）** が根拠条文つき

## 法令側の告示委任スポット

CiteGraph 検索DBのチャンクから「国土交通大臣が定める／指定する」等を検出：

- 出現 459か所、**190条**に分布（施行令135条、施行規則24条、建築基準法20条、建築士法5条、耐震改修促進法3条、建設業法3条）

## リンク結果

根拠条文（法令＋条）が一致する告示を候補として付与（確定ではなく候補提示）：

- **190スポット中 103スポット（54%）に1件以上の告示候補が付いた**
- 未リンクの主因：消防庁など国交省以外の告示（今回のコーパス外）、一覧に無い古い告示、根拠条文が本文冒頭に現れない告示

- 直接の候補 **9件**。中身は実務の本命そのもの：
  - 建設省告示第1399号「耐火構造の構造方法を定める件」
  - 建設省告示第1400号「不燃材料を定める件」
  - 建設省告示第1358号「準耐火構造の構造方法を定める件」
  - 建設省告示第1359号「防火構造の構造方法を定める件」
  - 建設省告示第1360号「防火設備の構造方法を定める件」 ほか
- 受け手（施行令107条など）経由でも18件追加

### 法12条（定期報告）— 直接の告示委任は無いが、受け手経由で本命に届く

- 施行規則第5条経由：国土交通省告示第282号（定期調査報告の項目・方法・判定基準）
- 施行規則第6条経由：第723号（防火設備）、第285号（建築設備）、第283号（昇降機）の定期検査告示
- 法6条（確認申請）も受け手経由で4件、法87条は19件
- 法77条の35は0件（受け手が別省令の世界であり、告示層では解決しない——例外の再確認）

## 限界（正直なところ）

- **粒度は条まで**。法2条のように号ごとに委任先が違う条では、別号あての告示も候補に混ざる（地下街・冷却塔の告示など）。号・項単位の照合は次の一手 (b) の課題と共通
- **現行性は未検証**。古い建設省告示には廃止済みのものも混ざりうる。出典URLと文書番号から原本確認できる形にしてある
- **網羅性は国交省一覧が上限**。消防法の告示（消防庁）や一覧未収載分は入っていない
- 改正告示は一覧に個別エントリとして混ざっているが、「どの告示がどれを改正したか」の関係整理は未実施（原文＋改正を並べる材料は揃った段階）

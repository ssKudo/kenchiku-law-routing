# Step 5：日本語リランカー混合版レポート（提案⑤の再戦）

## 測った仕組み（最初に明記）

- **CE側（主測定）**： hotchpotch/japanese-reranker-cross-encoder-small-v1。日本語特化の小型 cross-encoder（XLMRobertaForSequenceClassification、MiniLM-L12-H384、約118Mパラメータ、生成しない採点専用）。公式 ONNX 配布が無いため、torch（2.15.0+cpu）で読み込んで自前で ONNX 変換し、ONNX Runtime で実行した。変換の正確性は torch 出力との照合で検証済み（15ペアで最大差 1e-6）。
- **CE側（フォールバック、併せて実施）**： rerank_ce/ に保存済みの bge-reranker-v2-m3 ペアスコア（単独では 13/9.33 と大敗したもの）。
- **言葉数え側**： 連結スタック（原文＋単語タグ＋メタデータ）の生スコア。weighted_fusion と同一作法で再計算し、参照値と全問一致を検証済み。
- **混合式**： プール内で両スコアを Min-Max 正規化し、S = w言葉数え × スタック ＋ wCE × CE。(w言葉数え, wCE) ∈ {(0.8, 0.2), (0.7, 0.3), (0.6, 0.4)} の全パターンを報告する。
- **土俵**： fifty の50問・原文 TF-IDF 上位30プール。ペア採点の窓方式は rerank_ce と同一（[s] q [/s][/s] chunk [/s]、上限512トークン、窓幅 = 512 − (問題トークン + 4)、最大4窓・等間隔サンプリング（先頭含む）、条文スコア = 窓の最大値）。総ペア数 4,109（bge 測定と同数）、採点時間 1,708秒（約0.42秒/ペア、bge の約1/4）。
- **参照値（全て再検証済み）**： ベースライン 29/3.88、連結スタック 31/3.38、現行最良 スタック×ruri（α=0.80〜0.90）33/3.26〜3.33、bge単独 13/9.33、天井 top-3 42。
- 採点は問題ごとに逐次保存し、途中でサービス再起動によりプロセスが一度死んだが（41/50問時点）、保存分から再開して欠けなく完走した。

## 動きの内訳

- **日本語CE単独**： スタック比で入 3問（2019-3、2026-25、2026-3）／出 21問、改善 7／悪化 30。bge単独とほぼ同じ負け方。
- **スタック × 日本語CE 0.8/0.2**： 入 3問（2019-3、2020-1、2026-3）／出 1問（2025-23）。**0.7/0.3**： 入 3問（同上）／出 1問（2019-29）。**0.6/0.4**： 入 3問／出 6問と、CE の分量を増やすと崩れる。
- **スタック × bge CE 0.8/0.2（新最良）**： 入 3問（2019-3、2021-1、2026-3）／**出 0問**、改善 9／悪化 4。現行最良（スタック×ruri α=0.85）との比較でも、現行最良の top-3 を全部保ったまま 2021-1 を追加し、出は 0問。
- 救出の顔ぶれ： 2019-3（法6条、スタック4位→両CEとも単独1位）、2026-3（法6条、スタック4位）、2021-1（法2条、スタック5位→bge単独1位。ruri単独では12位だった）。CE が単独で正解を1位に置けた問題を、脇役の分量なら落とさず拾える、という形。

## 読み

1. **日本語特化でも単独リランカーは負ける**（13/8.88、bge と同水準）。「日本語で追加訓練すれば単独で勝てる」という形の提案⑤は、この土俵では否定された。負け方も bge と同じで、試験問題の方言（条文の用語そのまま）では、意味側の物差しは言葉数えの上位を壊す。
2. **しかし「脇役の混合」なら CE は効く**。日本語CE は 0.8/0.2 と 0.7/0.3 で 33 に届き（現行最良と top-3 同数、平均は 3.40/3.33 と互角〜やや劣る）。さらに、単独では大敗した bge でも 0.8/0.2 の混合で **34/3.14 と測定史上最良**になり、しかも出（落下）が 0問だった。「単独で大敗した CE でも、脇役の混合なら効くか」への答えは **はい**。
3. **分量が肝**： CE を 0.4 まで増やすと両モデルとも悪化する（28/3.79、32/3.36）。CE の役割は「言葉数えの団子状態への決定打」までで、主役にすると壊れる——提案①（重み付き和）の非対称設計と整合する。
4. ruri（埋め込み）と CE（ペア採点）は別の意味側信号で、どちらも最良混合は 33〜34 の帯に収まる。意味側の天井がこの辺りにあるのか、土俵（プール内・試験方言）の限界なのかは、この測定だけでは切り分けられない。

## 留保

- 33→34 の差は1問であり、ノイズの範囲内という留保は従来通り。ただし bge 0.8/0.2 は「出 0問・改善9／悪化4・現行最良の top-3 を全部保持」という形の良さがある。
- 重み {0.2, 0.3, 0.4} は測定前に課題として指定された格子であり、その中で最良セルを選ぶ post-hoc な読みには注意（同じ50問で選んでいる）。
- 日本語CE は fp32 のまま実行した（量子化なし）。ONNX 変換は自前だが torch との一致（最大差 1e-6）を検証済み。
- 未測定のまま残るもの： 選択肢ごとの採点（XLaw 方式）、ruri-reranker-small（DistilBERT 系）での同混合、CE と ruri の三者混合。

# フック語彙吸い上げ（Graph-Propagated Document Expansion）測定レポート

2026-11-15 / 別AIレポート提案キュー Step 4（クドウ承認済み）

## 測った仕組み（最初に明記）

- **入口は言葉数え（TF-IDF）**、展開は (c) と同一のグラフ展開（stage3 `Graph.expand`：種→逆引き委任受け手→引用先→引用元40件キャップ）。土俵は hook_search と同じ証拠ベース249問。
- 変更点は入口の検索対象テキストだけ：各フック条文の本文に、1ホップ隣接条文群から吸い上げた **child_keywords** を追加段落として足し、その拡張テキストで TF-IDF 検索して上位3フックを種にする。
- 対象フック集合は hook_search と同一：フックB（A5＝被参照数≥5の374条文 ＋ leave-one-out おなじみ、問題ごとに399〜400条文）を主測定、フックA（A5）でも測定。フック集合そのものは変えていない。

### 抽出ルール（測定前に固定・過去問データは不使用＝漏れなし）

1. 隣接条文群 N(h) = `Graph.expand(h)` の文脈キーから h 自身を除いたもの（tier1 逆引き委任受け手・tier2 引用先・tier3 引用元先頭40件）。
2. 隣接本文：エンジンコーパス（11法2,726条文）内ならその本文、外なら CiteGraph chunks の当該条文チャンク連結。
3. 候補語：(a) janome で隣接本文から抽出した名詞（数詞・接尾・代名詞・非自立を除く、2文字以上）、(b) エンジン TERMS（＋SYN値）のうち隣接本文に現れるもの。
4. cover(w) = 隣接条文のうち w を含む条文数。**cover ≥ 2 必須**。
5. idf(w) はエンジンと同じ式（df はコーパス2,726条文での部分文字列文書頻度）。
6. score(w) = cover × idf。フック自身の本文に既にある語は除外し、上位 **12語** を採用。
7. 付加方法：12語を連結した追加段落の gram をフック文書の gram と total に加算（見出しグラム不変）。IDF は元コーパスのまま固定。

構築結果：対象400フック（A5 ∪ おなじみ候補66）、キーワードなし6フック、平均11.66語/フック、候補語彙2,734語（うち TERMS 由来は採用語4,665件中905件）。

## 検証（ハーネスの忠実性）

- 参照条件（通常の種）を同一ハーネスで再実行し、(c) の results.json と **249問全問一致（不一致0）**。
- フックA5・B（原文）も再実行し、hook_search の records_checkpoint.json と **全問一致（不一致0）**。
- 拡張スコア計算（Engine.score_all の複製）は、無拡張時に全フック分で元スコアと誤差1e-9未満で一致することを確認。

## 結果（249問、strict / family）

| 条件 | strict | family | 文脈中央値 | 正解が種に直接入った問 |
|---|---|---|---|---|
| 参照（通常の種） | 62.7% (156) | 70.7% (176) | 57 | 113 |
| フックA (A5) | 55.4% (138) | 66.3% (165) | 73 | 77 |
| フックA＋吸い上げ (A5_exp) | 55.8% (139) | 66.3% (165) | 73 | 76 |
| フックB | 63.9% (159) | 72.3% (180) | 65 | 103 |
| **フックB＋吸い上げ (B_exp)** | **63.5% (158)** | **71.9% (179)** | 64 | 101 |

**結論：吸い上げは到達率を動かさなかった（B で strict −1問・family −1問、A で strict +1問・family ±0）。** この土俵の最良は引き続きフックB（63.9 / 72.3）。

## 吸い上げの実働と勝敗内訳

吸い上げが「効かなかった」わけではなく、「効いても相殺された」が正確な読み：

- 種の集合が変わった問題：B で **53/249問**、A で 60/249問。吸い上げ語が種のどれかと一致した問題は 239/249問（96%）。
- 元の順位が4位以下だったフックが吸い上げで種入りした問題は31問。ただし **元のスコアが0（＝吸い上げ語だけで引っかかった）種は全249問で0件**。つまり「子の語だけで初めて釣れた扉」は一度も起きなかった。
- 種スロット747件のうち約49%で、拡張後のスコアが元より**下がった**（語を足しても本文が長くなる分の正規化で薄まる）。

### 勝ち（仕組み通りだった例）

- **2017-21（正解：建築士法3条）**：B では建築士法3条は入口5位で種に入れなかったが、その子条文群から吸い上げた「構造設計一級建築士」「登録」が問題文と一致して2位に浮上し、直接到達（family・strict とも勝ち）。提案②の想定した橋そのもの。ただし全249問でこの型の勝ちはこの1問だけ。
- 2018-4（A条件、strict のみ勝ち）：法7条の6 が4位→3位（吸い上げ語「確認」「建築設備」「施工」「敷地」）で種入りし、法90条の3 に strict 到達（family は元々到達済み）。

### 負け（押し出しの例）

- **2020-10（正解：施行令20条の3）**：元は正解自身が種の3番手に入っていたが、吸い上げで施行令129条の2の4（吸い上げ語「エレベーター」）が浮上して正解を押し出し、未到達に転落。
- **2021-28（正解：法52条）**：橋になっていた施行令135条の16 が種から落ち（代わりに省エネ法29条が浮上）、未到達に転落。

### 未到達の内訳（B_exp、family）

- 文脈外（橋フックなし）17問 — フックBと同じ（集合を変えていないので当然）。
- 入口ミス（橋はあったが top-3 が外した）53問 — フックBの52問から1問増。**ボトルネックは今回も入口の top-3 精度**で、吸い上げはそこを押し上げも押し下げもした。

## 読みと留保

- **なぜ動かなかったか**：(1) 吸い上げ量が小さい（12語≒60グラム vs 本文数千グラム）うえ、長さ正規化で既存の一致が薄まる。(2) 隣接語彙は同じ法・同じ章のライバルフック同士で大きく重なるため、橋は正解の扉だけでなく一族全体に架かる — PRF のときに見た「クラスタごと浮く」現象と同じ型。(3) 抽出語の質にばらつき：法2条では「階数・スプリンクラー・廊下・区画」など子の具体語が拾えた一方、汎用語（ほか・前項・位置・設置）も混ざり、都市計画法58条の2 のように隣接が他法に広がるフックでは無関係な語（帰国・永住・配偶など）まで吸い上げた。
- **この測定で否定されるのは「cover≥2・cover×idf 上位12語を1ブロックで足す」という主形**であって、吸い上げ一般ではない。未測定の変種：吸い上げブロックへの重み付け（見出し並みに強くする）、フックごとの選択的吸い上げ、隣接を委任受け手だけに限る形、など。
- フック集合の天井（B の被覆 93.2%）は集合を変えない限り不変で、本測定もその内側の話。

# Step 1：BM25F（フィールド別重み付きスコア）の測定レポート（2026-11-15）

別AIの考察レポート提案③を、クドウの指示「順に全部試す」の Step 1 として測定した。

## 測った仕組み（最初に明記）

- **物差しは言葉数えだけ**（小型モデル・ベクトル不使用）。土俵は従来どおり fifty_measurement の50問、各問プール30条文。正解がプール外の8問は全条件で順位なし（分母50、平均順位はプール内42問）。
- 対象は現行最良スタック（原文＋単語タグ＋メタデータ連結、countermeasures 対策2(a)）。**連結をやめ、4フィールドに分けて別々に数え、重み付き和で合成する**：
  - body：条文原文（エンジンの full、見出し込み）
  - meta：章・節名＋指紋語＋数値トークン（countermeasures と同一構築のメタデータ文字列、平均66 gram）
  - tag：単語タグ（平均606 gram）
  - exception：例外節（fingerprint の fingerprints.json をそのまま再利用、平均497 gram、空の条文 185/463）
- 変種は2つ：
  - **F-TFIDF**：従来の自作TF-IDF（measure50 の score_docs）の式をフィールドごとに適用。長さ正規化もフィールドごとの平均長で実施。body には見出しブースト（cap_grams ×2.2 等）を含む（連結版と同一作法）。
  - **F-BM25**：本家BM25 をフィールドごとに適用。IDF はフィールド別にプール全463条文から計算。トークンは文字2/3gram＋TERMS（出現回数）。パラメータは提案値： body k1=1.2, b=0.75 / meta k1=1.2, b=0.3（中心パターンは b=0.0 も追加測定）/ tag k1=0.2, b=0.75 / exception k1=1.2, b=0.75。
- 重み： body=1.0 固定、meta∈{0.4,0.5,0.6} × tag∈{0.2,0.25,0.3} × exc∈{0.2,0.3,0.4} の**27パターン全て**を両変種で測定。診断用に「body のみ」「中心・例外なし」も測定。**全パターンを報告し、最良だけを拾わない。**
- 測定前に baseline（29/3.88）と連結スタック（31/3.38）を再計算し、**両方とも42問全問一致**を確認してから測った。内部整合チェックとして、F-TFIDF の「body のみ」は baseline と完全一致（29/3.88）した。

## 結果

参照： baseline **29 / 3.88**、連結スタック **31 / 3.38**（top-3 / 平均順位）。

グリッドの読み：
- **例外フィールドの重みが支配的な軸**：どの行でも exc 0.2 ＞ 0.3 ＞ 0.4 と単調。例外は「小さく足す」分には無害〜微効、重くすると確実に邪魔をする（指紋測定で「例外だけが無害だった」結果と整合）。
- meta の重み（0.4〜0.6）はほぼ効かない。tag は 0.25〜0.3 が 0.2 よりわずかに良い。
- 中心パターンの動き（vs連結）： 入り 2019-3（4→3）、2021-1（5→3）、2026-3（4→3）／出 2020-14（2→4）、2020-2（2→4）、2022-14（3→4）、2025-23（3→5）。4位以上の大きな動きはゼロで、穏やかな入れ替えのみ。

- **body のみ同士の比較が決定的**： BM25 の body 単独（28/4.48）は自作TF-IDF の body 単独＝baseline（29/3.88）に負ける。つまり敗因はフィールド分割ではなく、**スコア式そのものの交換**にある。
- 動きは大きい（改善11〜13問 vs 悪化14〜19問）。大仕事もある（2024-28： 7→1、2019-3： 4→1）が、大崩れも目立つ（2017-26： 2→20、2026-25： 12→30、2021-17： 1→7 ※例外なし中心）。
- meta の b（0.0 vs 0.3）はほぼ無差。提案範囲の下限でも変わらない。

## 読み

1. **提案の前提「連結すると本文の一致が薄まる」は、この土俵では測定できる形では現れなかった。** F-TFIDF は全グリッドで連結と互角（最良セル 31/3.31 vs 連結 31/3.38 は平均0.07差＝誤差の範囲）。理由として考えられるのは、連結版の長さ正規化が累乗0.3と緩く、文量の増加がもともと強く罰せられていなかったこと、そしてスコアが「合計」方式なので、タグ・メタの gram は薄めるより一致を足す側に働いていたこと。
2. **本家BM25 への式の交換は明確な負け。** この素材では、自作TF-IDF の付属品（見出しブースト×2.2、用語ボーナス、質問側 gram の繰り返し重み、緩い長さ正規化）が実働している。BM25 の b=0.75 の線形な長さ正規化は、長さのばらつきが大きい条文群では長い正解条文を強く罰する。なお本測定の BM25 は IDF をプール463条文から計算しており（エンジンは全コーパス約4,700件）、この差も混ざっている。「BM25 の式そのもの」の純粋な敗北とまでは言わない。
3. **例外フィールドの重み上限（0.2 程度まで）** は両変種で一貫した、グリッド内では一番はっきりした信号。
4. 副産物：フィールド別スコアの基盤ができたので、後続ステップ（Step 2 の融合、Step 3 の MaxP）はフィールド単位のスコアをそのまま再利用できる。

## 正直なまとめ

- Step 1 は**突破なし**。F-TFIDF（フィールド別）は連結スタックと互角止まりで、最良セルも誤差の範囲。F-BM25 は全パターンで連結未満、中心パターンで 28/4.21 と baseline の平均順位（3.88）すら下回った。
- 現行最良は引き続き連結スタック（原文＋単語タグ＋メタデータ、31/3.38）。
- 留保（従来どおり）： 重みグリッドは同じ50問で試して同じ50問で評価している（全パターン報告で拾い読みは避けたが、最良セルの数字は割り引いて読むこと）。この50問は全体より易しめで消防法・省エネ法の正解問題はゼロ。土俵は言葉数えの top-30 プール内。

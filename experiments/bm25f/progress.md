# BM25F（Step 1）進捗

## 指示
- 別のAIの考察レポート提案③（BM25F）を、クドウの「順に全部試す」の Step 1 として測定する。
- 現行最良スタック（原文＋単語タグ＋メタデータ連結、31/3.38）をフィールド別に分け直す。

## 設計（確定）
- フィールド: body（条文原文＝エンジン full）/ meta（章・節＋指紋語＋数値トークンのメタデータ文字列、countermeasures と同一構築）/ tag（単語タグ）/ exception（fingerprint/fingerprints.json の例外節）
- 方式は2変種:
  - F-TFIDF: 自作TF-IDF（measure50 の score_docs）をフィールド別に適用し、フィールドごとに長さ正規化してから重み付き和
  - F-BM25: 本家BM25 をフィールド別に適用（IDF はフィールド別にプール全463条文から計算）。パラメータは提案値: body k1=1.2,b=0.75 / meta b=0.3（範囲 0.0〜0.3、中心パターンでは b=0.0 も追加測定）/ tag k1=0.2 / exception k1=1.2,b=0.75
- 重み: body=1.0 固定、meta∈{0.4,0.5,0.6}×tag∈{0.2,0.25,0.3}×exc∈{0.2,0.3,0.4} の27パターン全測定＋診断パターン（body のみ / 中心・例外なし）。全パターンを報告し最良だけ拾わない。
- 検証ゲート: baseline（29/3.88）と連結スタック meta_append（31/3.38）を全問再現してから測る。

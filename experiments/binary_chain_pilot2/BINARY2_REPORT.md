# 二択の連続パイロット v2 報告書

## 結論（先行）

**前進しなかった。** ラベルを平たい日常語にし、軸を6本から15本に増やしても、正答条の順位は baseline を1問も上回らず、トップ3命中は0/5（v1 も0/5）。v1 と比べると2問改善・2問悪化で、対照問（2017-1）は1位から26位まで沈んだ。

最大の誤算は順位以前のところにある。**形式崩れが v1 の22/90回（24%）から150/225回（67%）へ激増した。** 内訳は、問題文・選択肢の文をそのまま書き写す「復唱型」が117回と支配的だった。ラベルを短く平たくしたことで、モデルが「2つのうち1つを選ぶ」という行為そのものを見失い、問題文の写しに逃げる率が上がったと考えられる。

ただし崩れは一様ではない。**情景が浮かぶ具体的なラベル対はほぼ守れた**（逃げる/燃えない: 崩れ1/15回、土地/電気や水道: 2/15回、安全/手続き: 3/15回）。壊滅したのは抽象的な対（使い方/大きさ: 15/15回全滅、意味/罰: 14/15回、役所/約束: 14/15回）。「短く平たく」ではなく「具体的に思い浮かぶ」ことが効く軸と効かない軸の分かれ目だった。

方式の天井は今回も高く、oracle（正答条の側をそのまま選択に使う）では全問1位だった。律速は今回も回答側であり、特に「有効な回答が返ってくる率」そのものが律速になった。

## 条件（v1 から変えたのは2点だけ）

- 軸: 6本 → **15本**。v1 の6軸は意味を変えずラベルだけ平易化（資格を持つ人の話→免許、言葉の定義の話→意味、罰則・処分の話→罰、契約・書面の話→約束、構造・重さの話→強さ、建物そのものの話→建物、建物の設備の話→電気や水道、等）。新規9軸を追加（使い方/大きさ、大きさ/場所、免許/約束、手続き/罰、検査/約束、意味/手続き、電気や水道/大きさ、逃げる/燃えない、強さ/場所）。
- 採点: 生の一致数ではなく**一致率**（一致軸数÷その条文が側を持つ軸数）を主スコアに変更（薄まり対策）。同率は TF-IDF 順。
- それ以外は v1 と同一: Qwen2.5-1.5B-Instruct Q4_K_M、llama-server、temperature 0.2、seed 42、各問×各軸3回（提示順 AB/BA/AB）、ラベルをそのまま書かせる形式、機械規則による側付け（中立あり）、多数決の決定規則。
- 実行: 225回、合計439.9秒（約2.0秒/回）。

### 軸ごとの明暗（形式崩れ回数 / 15回中）

- 守れた軸: 逃げる/燃えない **1**、土地/電気や水道 **2**、安全/手続き **3**、手続き/罰 8、大きさ/場所 9、免許/約束 9。
- 壊れた軸: 使い方/大きさ **15（全滅）**、意味/罰 14、役所/約束 14、火事/強さ 13、意味/手続き 13、電気や水道/大きさ 13、強さ/場所 13、免許/建物 12、検査/約束 11。
- **定義vs罰則軸は、意味/罰 と平たくしても 14/15回崩壊（v1 は 12/15回）で改善しなかった。** この軸の崩れはラベルの硬さが原因ではなかったことになる。

### ラベルの人気偏り（残った癖）

- 「土地」は land_vs_equipment で有効回答13回中12回、「燃えない」は逃げる/燃えない で14回中12回、「手続き」は安全/手続き で12回中10回選ばれた。内容と無関係に選ばれやすいラベルが依然としてある。
- 「免許」は person_vs_contract（免許/約束）では4回選ばれたが、person_vs_building（免許/建物）では「建物」に全敗（0/3）し、v1 の「資格を持つ人の話が選ばれない」問題は場所によって再現した。

## 具体例

**2017-21（29位→7位に改善）**: 正答条（建築士法3条）とモデルの選択が合った軸は、安全/手続き=「手続き」、免許/建物=「建物」、免許/約束=「免許」の3軸。一方、正答条が「大きさ」側を持つ3軸（使い方/大きさ、大きさ/場所、電気や水道/大きさ）はすべて形式崩れで選択なしとなり、伸びしろを失った。

**2017-1（対照、1位→26位に悪化）**: 合ったのは「安全」「火事」「建物」の3軸。外れたのは 土地/電気や水道（モデル=土地、正答条=電気や水道）、大きさ/場所（モデル=場所、正答条=大きさ）、逃げる/燃えない（モデル=逃げる、正答条=燃えない）、強さ/場所（モデル=場所、正答条=強さ）の4軸。「場所」「土地」という人気ラベルへの引力が、正答条を押し下げた。

**2017-22（7位→26位に悪化）**: 合ったのは「手続き」「免許」（免許/約束）、「電気や水道」の3軸。外れたのは 免許/建物（モデル=建物、正答条=免許）、役所/約束（モデル=約束、正答条=役所）、土地/電気や水道（モデル=土地）、検査/約束（モデル=約束、正答条=検査）の4軸。免許が主題の問題で、軸によって免許が選ばれたり建物が選ばれたりと、判断が軸の組み合わせに引きずられている。

## 留保

- 本測定は baseline 上位30条のプール内での並び替え効果のみを測ったもので、全条文検索の改善ではない。
- 軸・ラベル・側付けは結果を見てから変更していない。上記の「具体性が分かれ目」という観察は、次の設計への課題記録であり、本実験の条件には反映していない。
- 一貫性・位置バイアスの v2 の値は、有効回答だけに条件付けた参考値である。

## 課題（記録のみ・未実施）

- ラベルの設計軸は「短さ・平たさ」ではなく「情景の具体性」（逃げる/燃えない型）かもしれない。動詞や場面のある対は守れ、抽象名詞の対は壊れた。
- 軸を増やす前に、有効回答率そのものを上げる工夫（例: ラベルを文の形にする、選択肢を問題文の後に置く等）が律速の解消に直結する可能性がある。
- 人気ラベル（土地・場所・手続き）への引力を相殺する採点側の工夫（ラベルごとの選択頻度で割る等）も候補。

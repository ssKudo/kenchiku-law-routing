# qwen_reading_pilot について（途中停止の記録）

この実験は、言い換えた問題文と条文の看板を Qwen2.5-1.5B に1組ずつ読ませて「合う／合わない」を判定させる計画でしたが、処理速度の見積もり（プロンプト処理 約39トークン/秒、全条件で数時間規模）から、実施者の判断で**途中で停止**しました。

- 経緯と部分結果の要約は `progress.md` にあります。
- 測定スクリプトは `work/`（`build_materials.py`、`run_judgments.py`、`bench.py`）にあります。
- 判定の生データ（raw JSONL）は、問題文と条文テキストのペアそのものを含むため、本リポジトリには含めていません。
- 停止の結論は「小型モデルに全文を読ませて答えさせるのは、大規模モデルの仕事である」というもので、総括レポート（`report/REPORT_2026-11-15_小型モデルの座席表.md`）の「座席表」における「読ませる席＝壊れる」の根拠の一つです。

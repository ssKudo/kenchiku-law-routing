# 入口改善実験 総まとめ（2026-11-12）

## 前提

- 背景： (c) 本格版（過去問300問）で、入口（問題文→候補条文の当たり付け）の弱さが全体の天井と判明。種（TF-IDF上位3条）の正答命中は厳密45.4%、トップ1は26.1%。グラフ展開で+17.3pt（厳密62.7%）まで伸びるが、入口を外した問は全て未到達。
- この一連の実験は「入口をどう改善するか」の試行。共通の物差しとして、入口ミスの過去問5問（2017年 No.21 建築士法3条／No.22 建築士法20条／No.24 都市計画法58条の2／No.4 施行規則3条の2／No.1 施行令112条＝到達済みの対照）を使った。
- 測定系：問題文の TF-IDF 検索（(c) の engine）＋各方式の追加処理。モデルは Qwen2.5-1.5B-Instruct（GGUF Q4_K_M、llama.cpp、temp 0.2、seed 42）。
- 表の数字は「正答条の順位」。小さいほど良い。対照の No.1 は baseline で1位。

## 方式ごとの倒れ方

- **自由生成**：選択肢の写し、指示文の言葉自体を「用語」として出力、同じ語の反復。言い換えにならない。
- **番号選択 v1/v2**：番号例「3, 7, 12」のなぞり→例を消しても連番出力。問が違っても同じ出力。「番号で選ぶ形式」自体が合わない。
- **言葉選択 v3**：リスト先頭からの写し（8個上限も守れない）。1問だけ中盤からの本物の選択があった。
- **言葉選択 v4（実例つき）**：形は改善（先頭コピーは対照問のみ）。しかし優先順位付けはできず、橋語が9〜11番目に出て上限で切れた。順位改善ゼロ。
- **○×判定 v5**：97判定すべて×。形式遵守は全方式中最良（崩れ0）。判定内容が全否定に倒壊。橋語の拾い率 0/19。
- **看板**：唯一 baseline と互角（平均5.4）。No.24 が5→3位（「30日前までに届出」の言い換えが橋）。No.22 はライバル条文の看板に追い越され悪化。看板の文字量が原文比で数％しかなく効きが薄い。看板のみは全問悪化＝置換ではなく付加専用。
- **アキネーター式**：属性12問への具体的な読み取り質問でも回答は60回全部×（v5 の再発。抽象さが原因ではない）。全×の下ではタグの少ない条文が浮上し全問悪化。ハード消去なら正答条は序盤で消滅していた。
- **二択 v1**：全×崩壊は起きず、形式も概ね保持。ただしラベルの人気偏り（「建物そのものの話」13/15回 vs「資格を持つ人の話」2/15回）、入替提示で最初に出たラベルへ86.4%流れる位置バイアス、「定義vs罰則」軸で復唱崩れ集中。
- **二択 v2**：形式崩れが24%→67%に激増（問題文の復唱型）。ラベルを短く平たくすると「選ぶ」枠組み自体を見失う。ただし情景のある対（逃げる/燃えない等）は保持。意味/罰は定義/罰則から改善せず、軸の崩れは言葉の硬さが原因ではないと判明。相手のラベルで判断が反転する例あり（免許/約束→免許、免許/建物→建物に全敗）。

## 通して言えること

1. **設計側の天井は全方式で高い**。属性タグ・二択の軸・看板のいずれも、答え（選択）が正しければ正答条はほぼ1位に来る（オラクル行）。
2. **律速は一貫して「素の1.5Bの読み取り・判断」**。倒れ方は方式ごとに違う（連番・写し・全×・復唱・人気偏り）が、内容に追随した出力が安定しない点は共通。
3. baseline を上回った方式はゼロ。モデルを使わない「看板」が唯一互角だったが、それも横ばい止まり。
4. 候補リスト（エミリー作・全追加＝オラクル）自体の上限も 2/5 と低く、クエリ拡張路線には「候補の質」という別の弱点もある。
5. 未実施の切り分け：3Bモデルとの比較（大きさの問題かの決着）、手順の学習（LoRA等）による改善、人間が答える版（アキネーター式は方式として成立見込み）。

## 追補：日常文サニティチェック（同日夜）

「モデルが二択自体できないのか、読み物が難しいのか」を切り分けるため、同じプロトコルを短い日常文8文×二択（正解側は設計で決定）で実施。

- 多数決正解率 83.9%（成立31セル中26）。具体カテゴリ対 88.9%（24/27）、抽象対 50.0%（2/4）。単回有効回答の正解率は84.2%（対照：法令v1で多数決が正答条の側と一致した率は52.6%）。
- 形式崩れ 22.8%（法令v1の24.4%と同水準、v2の66.7%より大幅に良い）。内訳は文の復唱・断片、指示文の復唱、ラベルでない具体語（「飲料」「自転車屋」等、内容は掴んでいる近似も含む）。
- 位置バイアスは法令実験と逆向き（最初に出たラベルの選択率37.9%＝後出し優位）。向きが材料で反転する不安定な癖。入替一貫性68.0%は易しくしても上がらなかった。
- 抽象対の弱さは日常文でも残る（約束/たまたま は0/2、どちらも「約束の話」を選択）。崩壊は「ラベルが文中に無く、言い換え・推論が要るセル」に集中した（スマホの文）。

切り分けの結論：法令での壊滅は二択能力の欠如ではなく、読み物の難しさ（硬い長文＋抽象カテゴリ＋答えの語が文中に存在しない）が主因。逆に、材料を具体化・平易化すれば同じモデルでも選択が機能する場面がある。

## 追補2：質問タグ（doc2query型）パイロット（同日夜）

クドウの発案：看板（条文側の言い換え）ではなく、条文に「聞かれそうな質問文2〜3本＋問題文に出そうな単語10〜15個」をタグとして付ける。実行時は TF-IDF のみで、モデルは使わない。タグ作成は条文だけから（問題文・正答は見ない）。プール123条で測定。

- 一連の実験で初めて、baseline を上回る方式が出た（3問改善・悪化ゼロ）。
- 橋の実例：条文「三十日前」（漢数字）vs 問題文「30日前」（算用数字）を、タグの想定質問が受けて新規一致11グラム（No.24)。「十六メートル」vs「16メートル」も同型（No.21)。No.22 は新規の橋は少なく、「聞かれる部分の定番言い回し」の増量が効いた。
